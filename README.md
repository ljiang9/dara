# Dara 达拉棋

尼日利亚传统双人棋类，5×6 棋盘、纯 Python 标准库实现，带可复现的 AI 自动演示。

## 玩法

- **棋盘**：5 行 × 6 列，双方各 12 枚棋子（● 先手 / ○ 后手）。
- **布子阶段**：轮流放子，**不允许放出三连**（横/竖三连及以上都算违规，落子被拒绝）。
- **走子阶段**：每次把一枚子正交走一格到空位。若走出**恰好三连**（四连及以上不算），
  立即吃掉对方任意一枚子。
- **胜负**：对方只剩 2 枚子（已凑不出三连）或无子可走时，你获胜。

## 用法

```bash
python -m dara                                  # 人机对战（你是 ● 先手）
python -m dara --auto --games 10 --seed 42      # AI 对 AI 自动演示
python -m dara --auto --games 20 --seed 7 --verbose
```

人机对战中：布子输入 `行 列`（如 `2 3`）；走子输入 `起行 起列 到行 到列`（如 `2 3 2 4`）；
形成三连后按提示输入要吃掉的对方棋子坐标；`q` 退出。

## 诚实局限

- **AI 很弱**：布子只贪中心，走子只认"走出三连 + 随机"，不做深层搜索、不主动防守；
  熟悉规则的人类执任意一方通常能赢。`--auto` 只是演示引擎正确性，不是强度展示。
- 布子阶段若棋盘填满到无合法落子（极罕见），对局会判和棋收场；实测贪心 AI 下未出现。
- 文本回合制界面，无图形/动画/存档/悔棋；Python 3.10+，纯标准库。
